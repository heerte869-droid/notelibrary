# Bundled third-party licenses

Preserve these files when redistributing NoteLibrary.

- MacPaw/OpenAI: MacPaw-OpenAI-MIT.txt.
- Swift OpenAPI Runtime: swift-openapi-runtime-LICENSE.txt and swift-openapi-runtime-NOTICE.txt.
- Swift HTTP Types: swift-http-types-LICENSE.txt and swift-http-types-NOTICE.txt.
- LiteLLM DashScope mapping: LiteLLM-MIT.txt.
- KaTeX fonts: KaTeX-fonts-MIT.txt; the package license is also at ../KaTeX/LICENSE.
- Lobe Icons: ../AI_BRAND_ICONS_LICENSE.txt.
- libwebp: ../Tools/libwebp-COPYING and ../Tools/libwebp-PATENTS.
- libpng: libpng-LICENSE.txt.
- libjpeg-turbo / IJG: libjpeg-turbo-LICENSE.md and libjpeg-turbo-README.ijg.
- zlib: zlib-LICENSE.txt.
- LibTIFF: libtiff-LICENSE.md.
- Zstandard: zstd-LICENSE.txt.
- XZ Utils / liblzma: xz-COPYING.txt and xz-COPYING.0BSD.txt. Only liblzma is embedded; XZ programs and scripts are not included.

This software is based in part on the work of the Independent JPEG Group.

SOURCES.json records official license URLs and hashes. ../Tools/THIRD_PARTY.md records binary provenance and component-version evidence. Provider marks identify services without implying endorsement.
